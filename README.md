### 🌿 Featured Project

## HRL Green Spices — E-commerce Website

**A completed, deployed e-commerce website for an Indian spice business.**

I built HRL Green Spices to create an online shopping experience for customers exploring Indian spices and handcrafted spice garlands, while supporting the business's retail, wholesale, and OEM requirements.

🔗 **[Visit the Live Website](https://hrlgreenspices.co.in)**

**Project highlights**
- 🛍️ E-commerce experience for browsing and exploring products.
- 🌶️ Product-focused pages for cardamom, black pepper, and spice garlands.
- 📱 Responsive, visually engaging user interface.
- 🎨 Custom styling and reusable React components.
- 🔧 Backend development and database integration.

**Technologies:** React · JavaScript · Sass/SCSS · PHP · Laravel · MySQL · Git

This project helped me apply my development skills to a real business website, bringing together interface design, application functionality, and backend technologies.
